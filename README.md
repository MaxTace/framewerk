# Mise — система учета ингредиентов ресторана

Учебный Django-проект для учета ингредиентов, блюд, складских остатков и поставок. Структура и практики опираются на методические материалы ПР5, ПР6, ПР7 и ПР9: маршруты Django, шаблоны, SQLite, связанные модели, миграции и запросы ORM.

## Возможности

- каталог ингредиентов с категориями, единицами измерения и порогом остатка;
- карточки блюд и рецептуры с количеством ингредиента на порцию;
- загрузка и показ необязательных фотографий блюд;
- просмотр и ручная корректировка остатков;
- регистрация поставок с автоматическим увеличением остатка;
- поиск, фильтры, сортировка, агрегированные показатели и пагинация;
- административная панель Django;
- набор SQL-примеров для практики в `sql/queries.sql`.

Веб-представления построены на классах Django и работают через ORM, сохраняя фильтрацию и параметры пагинации. Поставки хранятся как отдельные записи; после их создания складской остаток увеличивается в рамках одной транзакции. Поставки в интерфейсе администратора доступны только для просмотра, чтобы не изменять историю поступлений задним числом.

## Запуск

Требуется Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Панель администратора: `http://127.0.0.1:8000/admin/`.

## Проверки и демонстрационные данные

```powershell
python manage.py check
python manage.py test
python manage.py makemigrations --check --dry-run
```

В режиме разработки Django Debug Toolbar отображается на HTML-страницах для
локальных запросов. Панели SQL и Profiling позволяют изучить запросы ORM и
время их выполнения. Маршрут панели: `/__debug__/`.

После входа в административную панель или через веб-интерфейс добавьте ингредиенты, рецептуры и поставки. Ингредиент создается с нулевым остатком; каждая новая поставка увеличивает его количество. Порог минимального остатка задается для каждого ингредиента отдельно.

Фотографии блюд загружаются через форму блюда и сохраняются в `media/dishes/`. В режиме разработки Django раздает их по адресу `/media/`.

## Структура данных

- `Ingredient` — ингредиент, категория, единица измерения и порог остатка.
- `Dish` — блюдо и цена в меню.
- `RecipeItem` — связь блюда с ингредиентом и его количеством на порцию.
- `Stock` — текущий остаток ингредиента.
- `Supply` — запись о поставке; связь с ингредиентом защищена от случайного удаления.

SQLite — база данных по умолчанию. Схема создается миграциями Django; SQL-скрипты в `sql/queries.sql` приведены для учебного анализа связей и агрегатов.
